# Демонстрационные данные

При обычном запуске автоматическая синхронизация TypeORM отключена. Для подготовки базы используйте `npm run db:setup`. При необходимости синхронизацию можно явно включить через `DB_SYNCHRONIZE=true` в `.env`.

Создание структуры и заполнение из AnimBook-server: `npm run db:setup`. По отдельности: `npm run db:schema`, затем `npm run seed`. Подключение берётся из локального .env.
Структура создаётся из моделей TypeORM в схеме DB_SCHEMA (по умолчанию public), без удаления существующих таблиц. Seed добавляет 4 категории, 4 издательства, 36 товаров, 144 характеристики и 4 баннера.
Повторный запуск пропускает существующие записи по demo-slug; существующие данные не удаляются и не перезаписываются. Добавление выполняется небольшими транзакциями с отдельными соединениями для совместимости с прокси Filess. При сбое повторный запуск продолжает заполнение без дубликатов.
Пользователи, реальные отзывы, заказы и платежи не создаются. Имена товаров и издательств вымышлены.
Иллюстрации находятся в AnimBook/public/demo; относительные URL рассчитаны на клиент AnimBook.

Если PostgreSQL отвечает "too many connections", освободите подключения на стороне провайдера и повторите команду. Seed использует одно подключение; сервер по умолчанию — максимум два (DB_POOL_SIZE).
